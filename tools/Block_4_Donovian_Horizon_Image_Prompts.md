# Operation Donovian Horizon Image Generator Prompts

Use these prompts to create richer images for the V2 capstone app. Keep images unclassified, fictional, and clearly marked for training use. Recommended aspect ratio: 16:9 or 3:2.

## Overall Style

Create a polished military intelligence training graphic, fictional modern conflict scenario, dark navy tactical interface palette, olive and muted green accents, red warning highlights, cream annotation text, clean labels, ESL-friendly visual clarity, no real-world flags, no gore, no photorealistic classified markings, "UNCLASSIFIED TRAINING USE" small footer.
